# CampusOverflow 用户手册

> 面向使用者（学生、教师、助教、管理员），v1.0.0。
> 开发与部署请看 `README.md`，架构决策看 `docs/adr/`，错误码全表看 `docs/错误码.md`。

打开浏览器访问 `http://localhost`（或课程部署的站点地址）即可使用。整站不需要安装任何客户端。

## 1. 注册与登录

**怎么做**

1. 点右上角「登录 / 注册」进入表单页。
2. 切到「注册」标签，填写：学号 / 工号（登录名）、密码、昵称、校园邮箱、学院、班级。
3. 点「注册并登录」。注册成功会直接登录，无需再输一次密码。

登录后顶栏右侧显示你的昵称与角色（学生 / 助教 / 教师 / 管理员），点昵称可进自己的声誉页，点「退出」结束会话。

**出错时会怎样**

| 情况 | 提示 / 错误码 |
| --- | --- |
| 密码不满足强度要求（需 8–64 位且同时含字母与数字） | `ID-1004`「密码不满足强度要求」 |
| 学号 / 工号或邮箱已被注册 | `ID-2001`「已被注册」 |
| 未登录就点「我要提问」或「通知」 | 跳到登录页（`AUTH-401`） |
| 1 分钟内连续 5 次密码错误 | `AUTH-429`「登录失败次数过多，请稍后再试」 |

> 登录状态保存在服务端会话里，关掉浏览器再打开通常仍是登录的；如果长时间不用，会话过期后会被要求重新登录。

## 2. 浏览、搜索与筛选

首页就是问题列表。顶部工具栏从左到右：

- **搜索框**：输入关键词，支持中文全文检索（按 2 字一组的粒度切分）。
- **标签筛选框**：输入标签名后**按回车**生效；右侧「热门标签」里点任意标签也能直接筛选。
- **排序下拉**：相关度 / 最新 / 最近活跃 / 得分最高。
- **「仅看未回答」「仅看悬赏」**：勾上即缩小范围，可与其他条件叠加。
- 每张问题卡片显示票数、回答数、浏览量、摘要、标签与作者。

只要动过上述任一条件，列表就进入「搜索模式」；清空条件即回到普通列表。列表分页显示，底部有「上一页 / 下一页」与总数。

**相关问题**：进入问题详情页后，右下角「相关问题」会列 5 条相似问题，并标出相似度百分比、回答数与是否已采纳。列表为空时显示「暂无」。

**出错时会怎样**

| 情况 | 提示 / 错误码 |
| --- | --- |
| 搜索词里某个词不足 2 个字符 | `DIS-1001`「每个词项至少 2 个字符」 |
| 搜索词超过 50 个字符 | `DIS-1002`「搜索关键词过长」 |
| 网络或服务异常 | 列表上方出现错误框与「重试」按钮，不会白屏 |

## 3. 提问与标签

**怎么做**

1. 登录后点工具栏的「我要提问」，进入「提出一个问题」。
2. 填写：
   - **标题**：10–150 字，写清楚「在什么场景、遇到什么现象」。
   - **正文**：Markdown，至少 20 字，建议写清「我试过什么、卡在哪里」。代码用三个反引号包裹。
   - **标签**：1–5 个，用空格或逗号分隔（例如 `数据结构 红黑树`）。
   - **所属课程**：可选，下拉里只出现你已选的课程；不选则归入公共列表。
3. 点「发布问题」，成功后自动跳到该问题详情页。

正文按 Markdown 渲染，渲染结果经过净化和过滤，粘贴进来的可疑 HTML 不会被执行。

**出错时会怎样**

| 情况 | 提示 / 错误码 |
| --- | --- |
| 标题太短（< 10 字）或太长（> 150 字） | `QA-1001`「标题长度不合法」 |
| 正文太短（问题 < 20 字，回答 < 10 字）或超过 3 万字 | `QA-1002`「正文长度不合法」 |
| 标签数量不是 1–5 个 | `QA-1005`「每个问题需要 1–5 个标签」 |
| 未登录 | 跳转登录页 |

## 4. 回答、评论与投票

**回答**：在详情页底部「写回答」框里输入内容（支持 Markdown，至少 10 字），点「提交回答」，回答会立刻出现在列表里。

**评论**：问题与每条回答下方都有评论区。

- 点「添加评论」输入内容，点「发表」。
- 点某条评论右侧的「回复」可针对该评论回复，形成一层楼中楼。
- 评论里写 `@昵称` 可以提醒对方（`@` 后接 2–20 个非空白字符），被提醒的人会收到通知；昵称写错或不存在时不会报错，只是不会发出提醒。

**投票**：每条问题与回答左侧有 ▲ / ▼ 与当前分数。再点一次同一个方向即撤销投票，反向点则是改投。未登录时按钮不可点。

**出错时会怎样**

| 情况 | 提示 / 错误码 |
| --- | --- |
| 给自己的问题或回答投票 | `QA-1015`「不能给自己的内容投票」 |
| 答案正文不足 10 字 | `QA-1002`「正文长度不合法」 |
| 同一条内容被快速重复投票（并发） | `SYS-409-DUPLICATE`「重复提交」，刷新后状态是最终结果 |

> 投票对声誉的影响**不是即时**的：计分是异步结算的（事件先写入发件箱，再由中继投递）。刚投完票看到分数变了但声誉没变，属正常现象，几十秒内会到账。

## 5. 采纳答案

**谁可以采纳**：提问者本人，或该问题的课程教师 / 助教。

**怎么做**：在想要的回答下方点「采纳此回答」。采纳后：

- 该回答左侧出现 ✔ 标记，卡片高亮；
- 该问题不能再被采纳第二次；
- 回答作者获得声誉 +15（若采纳你的人就是你自己，不加分）；
- 若该问题带着悬赏，且这正是悬赏要结算的那条回答，悬赏会同时结算给回答作者。

**出错时会怎样**

| 情况 | 提示 / 错误码 |
| --- | --- |
| 该问题已经采纳过了 | `QA-2002`「问题已采纳，不能重复采纳」 |
| 不是提问者也不是课程教师 / 助教 | `QA-3001`「只有提问者或课程教师/助教可以采纳」 |

## 6. 悬赏发起与倒计时

**谁可以发起**：课程管理者——课程教师、助教或管理员（`REP-3001`）。普通学生不能发起悬赏。

**怎么做**

1. 进入问题详情页，若该问题还没有进行中的悬赏，会看到「发起悬赏」链接。
2. 填写两个数字：
   - **积分**：10–500；
   - **悬赏天数**：1–14 天，下面会实时显示「预计截止」时间。
3. 点「确认悬赏」。积分会先从你的可用余额中**冻结**，问题仍未被采纳时到期自动退回。

**倒计时**：悬赏进行中时，问题正文下方会出现一条横幅「悬赏 N 积分 · 剩余 x天 hh:mm:ss」，每秒刷新；到期后显示「已截止」。同一问题同一时间只能有一个进行中的悬赏。

**结算规则**：悬赏跟随「采纳」结算——被采纳的那条回答的作者拿走积分。发起人不能赢自己的悬赏（`REP-1005`）。

**出错时会怎样**

| 情况 | 提示 / 错误码 |
| --- | --- |
| 问题已删除或已采纳，还想发起悬赏 | `REP-1001` |
| 可用（含冻结）积分不够 | `REP-1002`「可用悬赏积分不足」 |
| 积分不在 10–500，或天数不在 1–14 | `REP-1003` / `REP-1004` |
| 该问题已有进行中的悬赏 | `REP-2001` |
| 悬赏已结算或已关闭还想再结算 | `REP-2002` |
| 非课程管理者发起 | `REP-3001` |

## 7. 教师认证

**谁可以做**：该问题的课程教师 / 助教（与「可管理该问题」同一权限）。

**怎么做**：在任意一条尚未被认证的回答下方点「教师认证」，该回答作者处即显示「教师认证 · 你的昵称」。一条回答只能被认证一次；作者会收到通知并得到「名师认可」徽章。

**出错时会怎样**：无权限时按钮根本不出现；若通过其他方式触发，返回 `AUTH-403`（权限不足）。已认证的回答不会重复出现按钮。

> 「认证教师身份」本身（把某个账号认定为课程教师）目前由管理员在后台处理，页面暂不提供自助申请入口。

## 8. 通知中心

**在哪里**：顶栏「通知」，右侧红底数字是未读数，**每 30 秒刷新一次**（不是实时推送）。

**会收到哪些通知**

| 类型 | 触发 |
| --- | --- |
| 新回答 | 有人回答了你的问题（自己回答自己的不通知） |
| 回答被采纳 | 你的回答被采纳 |
| 教师认证 | 你的回答获得教师认证 |
| 被提及 | 有人在评论里 `@` 了你 |
| 悬赏奖励 | 你赢得了悬赏 |
| 获得徽章 | 你拿到了新徽章 |

**怎么做**：点某条通知会标记为已读并跳到对应页面（没有跳转目标的通知只标记已读）。顶部「全部标记为已读」可一次清空未读。列表分页，每页 20 条。

同一件事重复发生（例如事件被重投）不会给你重复的通知。

**出错时会怎样**

| 情况 | 提示 / 错误码 |
| --- | --- |
| 未登录点通知 | 跳登录页（`AUTH-401`） |
| 标记别人的通知为已读 | `DIS-3001`「只能标记自己收到的通知」 |
| 通知已被删除 / 不存在 | `DIS-4001` |
| 加载失败 | 出现错误框与「重试」按钮 |

> 红点最多滞后 30 秒；如果你刚触发了一个动作就盯着红点，请稍等半分钟或直接进通知页刷新。

## 9. 排行榜、徽章与声誉

**排行榜**：顶栏「排行榜」进入。四个页签：本周 / 本月 / 本学期 / 总榜。表格显示名次、用户、声誉值；已认证用户昵称旁有 ✔。某个周期没有数据时显示「这个周期还没有数据」。

**我的声誉页**：点顶栏自己的昵称，进入 `/users/{id}/reputation`，可看到声誉总值与你自己的流水明细（来源、变动、时间）。别人的流水不可见（`REP-3002`）。

**声誉怎么来**

| 事件 | 变动 |
| --- | --- |
| 回答被采纳 | +15（自己采纳自己不加） |
| 收到一个赞 | +10 |
| 收到一个反对 | −2 |
| 撤销赞 / 改投 | 按新旧差额回退或补齐 |
| 每日正向投票收益上限 | 200 分，超出部分当日不再累加 |

注册开户时按角色发放初始积分：学生 0、助教 500、教师 / 管理员 1000。

**徽章**

| 徽章 | 条件 |
| --- | --- |
| 初来乍到 | 提交第一个回答 |
| 初露锋芒 | 第一个回答被采纳 |
| 解惑达人 | 累计 10 个回答被采纳 |
| 名师认可 | 回答获得教师认证 |
| 小有名气 | 声誉达到 100 |
| 德高望重 | 声誉达到 1000 |

**出错时会怎样**

| 情况 | 提示 / 错误码 |
| --- | --- |
| 查看别人的声誉流水 | `REP-3002`「只能查看自己的声誉流水」 |
| 声誉账户不存在（极少数历史账号） | `REP-4001` |
| 刚操作完声誉没变 | 属正常：异步结算，见下方说明 |

> 声誉与排行榜是**异步结算**的：你的操作先写进事件表，由后台中继投递后再落账。通常几十秒内到账；如果长时间没变，多半是后台投递失败，需要运维查发件箱（这不是你能在前端解决的）。

## 10. 编辑与删除自己的内容

**编辑问题**：详情页问题下方「编辑」，可改标题、正文、标签；保存后正文与搜索索引同步更新。

**编辑回答**：自己回答下方「编辑」，只改正文。

**删除**：自己可删自己的问题；回答的作者或课程管理者可删回答。删除前会弹确认框「删除后不可恢复」。

删除是**软删除**：内容从列表、搜索、详情页消失，但数据行仍在库里（架构决策 ADR-006）。因此：

- 删除后该问题的链接会返回「不存在或已删除」（`404`）；
- 已删除问题上的悬赏无法再结算；
- 搜索里也不会再搜到它。

**出错时会怎样**

| 情况 | 提示 / 错误码 |
| --- | --- |
| 两个人在同一秒编辑同一条内容 | `SYS-409-CONCURRENT`「内容已被他人修改，请刷新后重试」 |
| 编辑他人内容（无权限） | 按钮不出现；强行调用返回 `AUTH-403` |
| 删除后再点进详情 | 404 |

## 附：常见疑问

| 疑问 | 说明 |
| --- | --- |
| 为什么我的通知不是秒到？ | 通知红点是 30 秒轮询（已知限制，未改成实时推送）。 |
| 为什么声誉/徽章慢半拍？ | 声誉走事件异步结算，不是同步写库。 |
| 中文搜索搜不到？ | 部署用的 MySQL 必须开启 ngram 分词（`ngram_token_size=2`）；自建数据库未按此配置时中文检索会退化。 |
| 能不能在页面上禁用某个账号？ | v1.0.0 不提供该功能，违规账号由运维在后台处理。 |
| 能不能自己改昵称 / 头像？ | v1.0.0 的个人资料只读，暂不支持自助修改。 |
