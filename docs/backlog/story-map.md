# 用户故事地图（User Story Map · Lab2）

> 需求建模工作坊产出 · 维护者：PO（zhaojeak）
> 结构：横轴 = 用户活动（Backbone 叙事流）；纵轴 = 发布批次（S0 → S4），越靠上优先级越高（MVP）。
> 卡片 = PBI 编号 + 用户故事；*斜体* 为 Should/Could，加粗为 Must。

## 用户活动（Backbone）

1. **身份与课程**：注册/登录 → 认证 → 课程浏览/加入/成员管理
2. **提问**：发布问题（标题/正文/标签/关联课程）
3. **浏览发现**：问题列表（分页/筛选）→ 详情（正文/回答/评论渲染）→ 热门标签
4. **回答互动**：提交回答 → 评论与一层回复 → @提及
5. **评价**：投票/改投/撤销 → 采纳 → 教师认证 → 编辑/软删除
6. **声誉激励**：开立账户 → 计分记账 → 徽章 → 排行榜 → 声誉档案/流水
7. **悬赏**：发起（冻结）→ 采纳结算 → 到期退款 → 倒计时
8. **搜索推荐**：关键词搜索 → 筛选排序 → 相关推荐
9. **通知**：事件通知 → 已读管理 → 实时刷新
10. **管理运营**：管理员认证/建号 → 禁用账号 → 对账 → 监控/部署
