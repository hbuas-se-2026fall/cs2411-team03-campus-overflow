# ADR-010 各角色初始悬赏积分

## 状态
已接受（Sprint 2 PO 决策）

## 背景
`ReputationRulebook.initialPoints(Role)` 在用户注册开户时发放悬赏积分（与声誉是两种货币：声誉不可花，悬赏积分可冻结/打赏）。

V3 指导书只规定了 TEACHER=1000、STUDENT=0，TA 与 ADMIN 的取值明确"建议 PO 决定"。

## 决策
| 角色 | 初始悬赏积分 | 理由 |
|---|---|---|
| STUDENT | 0 | 学生不能发起悬赏，只能赚声誉 |
| TA | 500 | 助教需要偶尔发起悬赏，但频次低于教师，给教师一半 |
| TEACHER | 1000 | 主责激励讨论，高频发悬赏 |
| ADMIN | 1000 | 与教师对齐，且 Admin 可发起课程管理操作 |

## 后果
- `ReputationRulebook.initialPoints` 按上表 switch 返回。
- 测试断言：TEACHER=1000、STUDENT=0（V3 强制）；TA=500、ADMIN=1000 为本 ADR 新增。
- 后续若课程运营发现 TA 500 不够，改这个 ADR 一处即可，业务代码不变。
